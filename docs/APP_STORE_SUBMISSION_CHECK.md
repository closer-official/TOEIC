# App Store 申請時のチェックリスト（現段階）

## 購入フロー（取引・購入）の確認

### 購入したら自分の装備として追加されるか
**はい。** `POST /api/exchange/purchase` で以下を行っています。

- 購入者の `profiles.gems` から代金を減算
- 出品を `status: 'sold'` に更新
- 購入者の `user_equipment` に、出品の **equipment_id, grade, level, effect_base** をそのまま 1 件 insert

→ 取引ページの「購入」で買った装備は、**装備ページ（持物）** にそのまま追加されます。

### チップはしっかり消費されるか
**はい。** 同じ API 内で以下を実施しています。

1. 購入者の `profiles.gems` を取得
2. `buyerGems < price` の場合は 402 で「チップが足りません」を返却（チップは減らない）
3. 問題なければ `profiles` を更新  
   - 購入者: `gems = buyerGems - price`  
   - 販売者: `gems += floor(price * 0.9)`（1 割は焼却）

チップは購入者から確実に減り、販売者には 90% が入ります。

## App Store に申請する場合に足りない／確認したい要素

### 1. 課金方式（最重要）

| 項目 | 現状 | 必要な対応 |
|------|------|------------|
| **Apple アプリ内課金（IAP）** | チップ・サブスクは **Stripe**（Web 決済）のみ | **App Store 経由で配布するアプリ**で、アプリ内でチップやサブスクを売る場合は **Apple IAP が必須**。Stripe のみだと審査で却下される可能性が高い。 |
| **対応の選択肢** | - | (A) **ネイティブ／ラッパーアプリで出す場合** … チップ・サブスクを **Apple IAP** に移行する。(B) **PWA のみ**（ストアに申請しない） … 現状の Stripe のままでよい。 |

### 2. 購入まわり（IAP を導入する場合）

| 項目 | 現状 | 必要な対応 |
|------|------|------------|
| **購入の復元（Restore）** | なし | サブスク／消耗型・非消耗型 IAP を提供する場合、**「購入を復元」ボタン** がほぼ必須。同一 Apple ID での復元に対応する。 |
| **領収書・解約案内** | 規約・FAQ で言及あり | 解約方法（設定アプリ等）の案内をアプリ内にも明示すると安心。 |

### 3. アカウント・データ

| 項目 | 現状 | 必要な対応 |
|------|------|------------|
| **アカウント削除（退会）** | 設定に「退会」あり（`/api/account/delete`） | ✅ 要件は満たしやすい。申請時に「アカウント削除の導線」を説明できる。 |
| **削除の明示** | 規約・プライバシーで「設定から削除可能」と記載 | 問題なし。 |

### 4. 法的・表示

| 項目 | 現状 | 必要な対応 |
|------|------|------------|
| **利用規約** | `/terms` に本文あり | サービス名が「SHUN」のままの箇所があれば「All-in ENGLISH」に統一するとよい。 |
| **プライバシーポリシー** | `/privacy` あり | 同上、サービス名・運営者名の表記を確認。 |
| **特定商取引法に基づく表記** | 要確認 | 有料販売する場合、事業者名・連絡先・返金等の表記が必要。`/about` や専用ページで用意。 |
| **会社概要・運営者情報** | `/about` で記載あり | 連絡先（メール・電話）が審査で見られる場所に載っているとよい。 |

### 5. 審査でよく見られる点

| 項目 | 現状 | 備考 |
|------|------|------|
| **問い合わせ先** | FAQ・about 等にメール記載あり | サポート用メール／URL を App Store の「サポートURL」にも一致させる。 |
| **年齢レーティング** | 未設定 | App Store Connect で適切なレーティングを選択。 |
| **カテゴリ** | 未設定 | 教育 or ゲームなど、内容に合うカテゴリを選択。 |
| **スクリーンショット・説明文** | 要準備 | 各デバイスサイズ用スクリーンショット、短い説明・キーワードを用意。 |

### 6. ネイティブアプリとして出す場合の追加

| 項目 | 現状 | 必要な対応 |
|------|------|------------|
| **ビルド** | Next.js（Web） | Capacitor / Expo 等でラップして iOS ビルドを作成。 |
| **アプリアイコン** | PWA 用あり | 1024x1024 など、App Store 用の解像度を確認。 |
| **スプラッシュ** | 要確認 | 起動画面の有無・内容を確認。 |

## まとめ（申請を出すとしたら）

1. **課金**  
   - **ストア申請する iOS アプリ**でチップ・サブスクを売るなら → **Apple IAP 必須**。現状の Stripe のみでは不足。  
   - ストアに出す予定がなく **PWA のみ** なら → Stripe のままでよい。

2. **すでに足りているもの**  
   - 購入時は「自分の装備に追加」「チップ消費」が正しく動いている。  
   - 退会（アカウント削除）の導線あり。  
   - 利用規約・プライバシー・会社概要のページあり。

3. **申請前に揃えたいもの**  
   - **Apple IAP** と（必要なら）**復元**。  
   - 規約・プライバシー・about のサービス名・運営者名の統一。  
   - 特定商取引法表記（有料提供する場合）。  
   - 問い合わせ先・サポート URL の明示と、App Store Connect との一致。
