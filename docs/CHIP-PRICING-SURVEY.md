## 4. 相場との比較・気になる点

### 4.1 チップ単価のばらつき（パック間）

- **mini だけ 1円=1チップ**で、他パックより単価が悪い（意図的な「少額＝割高」ならよくある設計）。
- small〜xxl は「買うほどお得」になっており、**パック間の比率は一貫**しています。
- 相場として問題になりやすいのは「**mini を買った人だけが不当に不利**」と感じるかどうか。50円でお試し、という位置づけなら許容範囲です。

### 4.2 ガチャ単価（円換算）

- 1回 300チップ → **mini 換算で 300円、xxl 換算で約 200円**。
- 一般的なモバイルガチャは 1回 300〜500円程度が多いため、**xxl ベースだとやや安め**。無課金〜少額課金で mini/small を買うユーザーには 300〜330円程度で、やや安い印象。
- 10連 2,700チップ（1回あたり270チップ）は **約10%割引**。業界では 10〜20% 割引が多く、**やや控えめ**だが突出して安すぎるわけではない。

### 4.3 スタミナ回復（10チップ/1）

- 1スタミナ = 10チップ ≒ **約7〜10円**（パックによる）。
- 「1プレイ」の価値として、学習系アプリでは **妥当〜やや安い** 範囲。

### 4.4 ギルド作成 500チップ

- 約 **350〜500円**（パック単価による）。一度きりの課金として **妥当な水準**。

### 4.5 イベント内価格

- **双六**: サイコロ 100チップ、黄金のダイス 300チップ。ガチャ1回と同額で「出目指定」が買えるので、**イベントとしてはややお得**に感じる可能性。
- **タワー**: オイル 300 / マット 200 / マスターキー 500。ガチャ・ギルド作成と同レンジで、**他コンテンツと整合的**。
- **一番くじ**: 1箱 100チップ。他コンテンツの単価と比べて **安め**（ガチャ1回の1/3）。

### 4.6 明らかにずれている／要確認と判断した箇所

1. **mini パック（50円=50チップ）**
   - 全パック中で**唯一 1円=1チップ**。small の単価（1.1チップ/円）に合わせると 50円≒55チップが自然。
   - **推奨**: 「お試し用で意図的に割高」ならその旨を表記するか、55チップに揃えると他パックとの整合が良い。

2. **サブスクのチップ単価**
   - Pro は 0.8円/チップ（medium と同程度）、Ultra は 0.75円/チップ（large と同程度）。**スタミナ・スピン回数込み**なので、チップだけ見ると「ややお得」で、大きなずれはなし。

3. **取引所レート（変動）**
   - 通常は 0.01〜0.5 gems/XP の範囲。**固定レート時は 1 XP = 10 チップ**。
   - 10チップ = 1スタミナなので「1 XP ≒ 1スタミナ」の感覚。プレイで得る XP 量次第で、**体感のバランスが変わる**ため、運用で調整する前提でよい。

4. **双六サイコロ 100チップ**
   - ガチャ1回の 1/3。イベント用の「安い消費」として意図していれば問題なし。**「ガチャよりイベントを回したい」**層には有利な設計。

## 6. まとめ

- **全体的に「やや安め〜妥当」**で、突出して相場から外れた高設定はありません。
- **要検討**: **mini パックの 50円=50チップ**だけ単価が他より悪い。意図的なら表記で補足、または 55チップなどに揃えると一貫します。
- **整合性**: ガチャ・スタミナ・ギルド・イベントのチップ消費は、同じパック単価で円換算したときにも**大きな矛盾はありません**。双六・一番くじはやや安く、「イベント特化」の価格設計と読めます。

必要なら、mini のチップ数変更案や、サブスク付与チップの微調整案も具体的な数値で出せます。
