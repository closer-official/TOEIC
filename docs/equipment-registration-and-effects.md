# 装備の登録方法と効果一覧

## 1. 装備の登録方法（武器・装備の追加・変更）

### どこで管理されているか

- **マスタデータはコードのみ**です。DBには「装備マスタ」テーブルはありません。
- 定義場所: **`src/lib/equipment-items.ts`**
- 配列 **`GACHA_EQUIPMENT`** に `EquipmentItem` を追加・編集すると、ガチャ排出・API・インベントリ表示に反映されます。

### 反映のしかた

- **Git でコードを変更し、デプロイ（ビルド）すると反映されます。**
- ランタイムでDBをいじるだけでは新しい装備は増えません。必ず `equipment-items.ts` を編集してください。

### 1件の装備に必要な項目

```ts
{
  id: string;           // 英小文字・アンダースコア（例: 'rensa_glass_pen'）
  name: string;         // 表示名（例: '連鎖の万年筆'）
  slot: 'weapon' | 'head' | 'torso' | 'feet';
  slotLabel: string;    // 表示用（例: '武器'）
  trait: '特定条件' | '安定スコア' | '経験値' | '時間延長' | '博打要素';
  rarity: 'SR' | 'R' | 'N';   // ガチャ排出レアリティ
  baseRate: number;     // 同一スロット内の排出重み（%）。合計100になるように
  effect: string;       // 効果説明文（UI表示用）
}
```

### コモン／ノーマルなどの「グレード」について

- **ガチャで手に入るのは常に「コモン」**です。`user_equipment` の `grade` は `common` で登録されます。
- ノーマル・レア・エピック・レジェンダリー・エターナルは **同一装備5個で進化** すると次のグレードが1個付与されます（`/api/equipment/evolve`）。
- グレードの定義は `equipment-items.ts` の `EquipmentGrade` と `EQUIPMENT_GRADES` です。**登録方法の違いはなく、すべて同じ `GACHA_EQUIPMENT` に id を追加するだけ**で、その装備がコモンとしてガチャに登場し、進化でノーマル以降になります。

## 3. グレード・レベルと効果倍率（前グレード引き継ぎ・掛け算方式）

### グレード進化

- **コモン → ノーマル → レア → エピック → レジェンダリー → エターナル**
- 同じ `equipment_id` ＋ 同じ `grade` の装備を **5個消費** すると、次のグレードが **1個** 付与される。
- **進化後は level 0** になるが、**効果倍率の基準値（effect_base）は消費した5個のうち最大の倍率**が引き継がれる。

### 効果倍率の計算

- **倍率 = effect_base + perLevel × level**
- `perLevel` = グレードごとのレベルあたり加算: コモン 0.001、ノーマル 0.002、レア 0.003、エピック 0.004、レジェンダリー 0.005、エターナル 0.006
- ガチャ取得時: `effect_base = 1`
- 進化時: 消費した5個それぞれの「その時点の倍率」の**最大値**が、進化後の1個の `effect_base` になる。

例:

- コモン Lv5: 1 + 0.001×5 = **1.005**
- この状態でノーマルに進化 → ノーマル Lv0、**effect_base = 1.005** → 倍率 **1.005**
- ノーマル Lv8: 1.005 + 0.002×8 = **1.021**
- この状態でレアに進化 → レア Lv0、**effect_base = 1.021** → 倍率 **1.021**

### DB・API

- `user_equipment.effect_base`: そのスタックの基準値（デフォルト 1）
- 装着時は `profiles.equipped_*_effect_base` に同じ値を保存し、GET で返す
- `equipmentEffectMultiplier(grade, level, effectBase)` で倍率を算出

## 3.5 エターナルのかけら・エターナル素材（レジェンダリー→エターナル進化用）

**装備・武器をレジェンダリーからエターナルに進化させる**には、通常の「同装備5個」に加えて **エターナル素材** が1個必要です。エターナル素材は「かけら」を集めて作ります。

### 概念

| 名前 | 説明 |
|------|------|
| **エターナルのかけら** | レジェンダリー→エターナル進化に必要な素材の欠片。すごろくイベントの「エターナル・アルター」マスで1個獲得できる。 |
| **エターナル素材** | かけらを10個集めて変換すると1個できる消耗品。**1個消費**すると、レジェンダリー装備を**1つ**エターナルに進化できる。 |

### 流れ

1. **獲得**: すごろくで「エターナル・アルター」に止まると **エターナルのかけら** が1個もらえる（`sugoroku_progress.fragments`）。
2. **変換**: かけらが **10個** 溜まったら、持物またはすごろく画面から「エターナル素材に変換」で **エターナル素材** 1個に変換する（`user_inventory` の `eternal_material`）。
3. **消費**: 持物の「進化」で、同じレジェンダリー装備5個を選んで進化するとき、**エターナル素材を1個消費**してエターナルに進化する。

### まとめ

- **エターナルのかけら × 10** → **エターナル素材 1個**（変換で作成）
- **エターナル素材 1個** → **レジェンダリー装備 1つ** をエターナルに進化（進化時に消費）

## 4. 追撃のヒール（evolution_buff）のトリガーについて

ゲーム内に「レベルアップ」の概念がないため、**現在は「ゲーム開始から30秒間」**でバフを発動しています。

別トリガーに変更する場合の候補（バランス調整用）:

| 案 | 説明 | メリット |
|----|------|----------|
| **ゲーム開始30秒**（現状） | 開始直後から30秒間 | 実装済み。序盤を安定させる。 |
| **コンボN到達時から30秒** | コンボが10（または5）に到達した瞬間から30秒 | 「追撃」のイメージに近い。連続正解のご褒美。 |
| **正解数N問到達時から30秒** | 累計正解が10問（など）に達した瞬間から30秒 | プレイ時間に依存しにくい。 |
| **残り時間が○秒以下で発動** | 残り30秒以下で発動し、終了まで持続 | 終盤の逆転用。逆境のモノクルと役割が似る可能性。 |
| **初コンボ断時から30秒** | 初めてコンボが途切れた直後から30秒 | 「巻き返し」バフ。1プレイ1回。 |

必要に応じて上記のいずれかに差し替え可能です。コード上の発動条件は `src/app/game/page.tsx` の `evolutionBuffEndMsRef` をいつセットするかで制御しています。
