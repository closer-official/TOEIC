## 枡名の「ばらけ」について（UI側）

現状、画面上では同じ `name` が繰り返し表示されるため、**ユーザーには「ネオン・エリア」「ストレート・ロード」が連続して見える**。イラストで各枡の見た目を差別化すれば、盤面図上では番号やイラストで区別できる。必要であれば、表示名を「ネオン・エリア（2番）」のように番号付きにする、または枡ごとに短いサブ名（例: ネオン・ゲート、ネオン・ストリップ、ネオン・アーケード、ネオン・エンド）を定義する案も検討できる。
