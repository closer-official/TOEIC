## 2. 概要（4,000文字以内）

```
All-in ENGLISH は、TOEIC対策に特化した単語・Part5（文法・語彙）の練習アプリです。

【主な機能】

■ 単語モード
TOEIC頻出単語を4択で出題。60秒の制限時間内にできるだけ多く正解し、スコアを競います。自分の苦手な単語を登録して練習できる「For You」モードも用意しています。

■ Part5モード
文法・語彙の空所補充問題を、同じく60秒サバイバル形式で解きます。本番に近い形式でスピードと正確さを鍛えられます。

■ 全国ランキング
毎週のスコアで全国のユーザーとランキングを競えます。自己ベスト更新を目指して繰り返しプレイできます。

■ ギルド
仲間とギルドを作り、研究室を強化してスタミナ上限やXP倍率などのバフを共有。チャットや週間ランキングでコミュニティを楽しめます。

■ ガチャ・装備
プレイで獲得したチップでガチャを回し、装備を集めましょう。装備はスコア倍率やスタミナ回復など、プレイに有利な効果を持ちます。

■ 大会（週1回）
日曜の開催時間中、Part5と単語を各1回プレイし、合計スコアで大会ランキングを競います。

【こんな方に】
・TOEICのスコアアップを目指している方
・すきま時間で手軽に英語の勉強をしたい方
・ゲーム感覚で続けやすい学習アプリを探している方

無料でダウンロードでき、基本的なプレイは無料のままお楽しみいただけます。追加のチップや便利機能はアプリ内購入でご利用いただけます。
```
