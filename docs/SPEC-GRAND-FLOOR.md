# THE GRAND FLOOR 仕様（実装状況）

全ギルドが同一マップで領土を拡大・占領する常設コンテンツ。実装済みと未実装を整理する。

---

## 1. マップ構造・地形

| 項目 | 仕様 | 実装 |
|------|------|------|
| 初期マップサイズ | 100×100 マス | ✅ `grand_floor_world.width/height`、生成時 100 |
| 山脈 | 進入・占領不可。全体の 3〜5% をランダム配置 | ✅ `generateMountains`（MOUNTAIN_RATIO_MIN/MAX） |
| 動的拡張 | 可動域の 80% 占領で上下左右に 50 マスずつ拡張（100→200 等） | ❌ 未実装。ワールドは初回生成時のみで拡張なし |
| 特殊資源 | 15×15 の各区画に最低1つは資源マス（chip_mine/delphi/hermes をローテ） | ✅ `generateResources` で区画ごとに1セル配置 |

---

## 2. 初期配置（チェックイン）

| 項目 | 仕様 | 実装 |
|------|------|------|
| 候補地 3 パターン | 要塞型・資源型・フロンティア型を各 1 箇所提示 | ✅ `findThreeCandidates`（要塞/資源/フロンティア） |
| 他ギルドとの距離 | 候補は既存陣地から上下左右 5 マス以上 | ✅ `HQ_BUFFER: 5` |
| 選択権 | ギルドリーダーが 3 候補から 1 つを選択して本拠地に | ✅ POST `/api/grand-floor/check-in` |
| 本拠地の固定 | 一度設置したら変更不可 | ✅ `guilds.grand_floor_hq_x/y` 更新なし |

---

## 3. 領土拡大・重ねがけ

| 項目 | 仕様 | 実装 |
|------|------|------|
| 実行権限 | リーダー・幹部のみ | ✅ expand API で role チェック |
| 拡大可能範囲 | 自陣に隣接する上下左右のマスのみ（斜め不可） | ✅ `orthogonalNeighbors` で隣接判定 |
| 基本コスト | Level 1: 1 マス 5000 XP | ✅ `expansionCostXp(1)` |
| 重ねがけコスト | Cost_n = 5000 × 2^(n-1) | ✅ `expansionCostXp(level)` |
| 重ねがけ制限 | 同一マスは 1 日 1 回まで | ✅ `last_stack_at` と DATE 比較 |
| 城の定義 | 同一マス Level 5 で「城」 | ✅ Level 5 = 城、占領コスト 3 倍 |
| 城の周囲自動付与 | 城建設時・城奪取時に周囲 1 マスを自陣に | ✅ `castleNeighborCells` と expand 内で自動付与 |

---

## 4. 占領・サプライライン

| 項目 | 仕様 | 実装 |
|------|------|------|
| 敵マス占領コスト | 累計 XP の 2 倍（城は 3 倍） | ✅ `conquerCostXp` |
| 奪取後の城 | 城は Level 5 のまま奪ったギルドの城に | ✅ conquer 時に level 維持 |
| サプライライン | 本拠地＋城をアンカーに、接続されていない領土は中立化 | ✅ `computeConnectedTerritoryForGuild` + `applySupplyLineCut` |
| 切断時の処理 | 切断された島のセルは一括で中立（guild_id 消去等） | ✅ conquer API 内で敗者側に supply line cut 適用 |

---

## 5. 特殊資源の効果（仕様のみ・未実装）

| 資源 | 仕様 | 実装 |
|------|------|------|
| チップ鉱山 | 占拠している間、一定時間ごとにチップを取得可能 | ❌ `grand_floor_mine_claims` テーブルはあるが、取得 API・UI なし |
| デルポイの託宣所 | 占拠中、一定範囲内の敵ギルドの「蓄積 Guild XP」「進軍予定」をマップ上に透過表示 | ❌ 未実装 |
| ヘルメスの泉 | 占拠中、メンバー全員のスタミナ回復 +20%、領土拡大時の Guild XP 消費 -10% | ❌ 未実装 |

---

## 6. ランキング・報酬

| 項目 | 仕様 | 実装 |
|------|------|------|
| ランキング指標 | 占領マス数・城数・占領日数を加味したスコア | ✅ リアルタイム: `cellCount + castleCount*10 + min(occupationDays,365)` |
| リアルタイムランキング | 現在のスコア順 Top 50 | ✅ GET `/api/grand-floor/ranking` |
| 過去日付スナップショット | 指定日のランキングを参照 | ✅ `?date=YYYY-MM-DD` で `grand_floor_daily_ranking` を参照 |
| 日次スナップショット登録 | 毎日 1 回、その時点のランキングを `grand_floor_daily_ranking` に保存 | ❌ 未実装（cron/ジョブなし） |
| 報酬配布 | 1 位 / 2–3 位 / 4–10 位 / 参加賞で XP 以外（チップ・限定アイテム・素材） | ❌ 未実装（報酬付与ロジック・UI なし） |

## 7. マップ表示・操作（UI）

| 項目 | 仕様 | 実装 |
|------|------|------|
| マップ専用ページ | マップだけを表示するページへ遷移 | ✅ `/guild/grand-floor-map` |
| ビューポート取得 | 表示範囲に応じて地形・セル・資源を API で取得 | ✅ GET `/api/grand-floor/map?minX,maxX,minY,maxY` |
| パン・ズーム | 上下左右移動・＋／－でズーム | ✅ 中心座標と span で再取得 |
| 本拠地中心 | 表示を本拠地に合わせる | ✅ 「本拠地」ボタン |
| トップバーとの重なり | コンテンツが固定ヘッダーに隠れない | ✅ `content-below-header` を適用 |
| 色分け | 自ギルド・他ギルド・山・未占領資源を区別表示 | ✅ 自=黄/オレンジ、他=HSL、山=灰、資源=黄/紫/青 |
| マス選択で拡大 | マップ上でセルをタップして「拡大」実行 | ❌ 未実装（拡大は API のみ） |
| マス選択で占領 | マップ上で敵セルをタップして「占領」実行 | ❌ 未実装（占領は API のみ） |
| 拡大・占領の確認 | コスト表示・確認ダイアログ | ❌ 未実装（ギルドタブに説明のみ） |

## 8. API 一覧

| エンドポイント | 役割 | 実装 |
|----------------|------|------|
| GET `/api/grand-floor/world` | ワールド 1 件取得（なければ生成） | ✅ |
| GET `/api/grand-floor/map` | ビューポート内の地形・セル・資源 | ✅ |
| GET `/api/grand-floor/state` | 自ギルドの参加状況・本拠地・領土数・城数 | ✅ |
| GET `/api/grand-floor/check-in` | チェックイン候補地 3 箇所取得 | ✅ |
| POST `/api/grand-floor/check-in` | 本拠地の設置（x, y 選択） | ✅ |
| POST `/api/grand-floor/expand` | 領土拡大または重ねがけ（body: { x, y }） | ✅ |
| POST `/api/grand-floor/conquer` | 敵マス占領（body: { x, y }） | ✅ |
| GET `/api/grand-floor/ranking` | リアルタイム／日付指定ランキング | ✅ |

## 9. 未実装まとめ（マップ関連を含む）

- **動的マップ拡張**: 占領率 80% でマップを 50 マスずつ拡張する処理。
- **チップ鉱山の取得**: 鉱山マス占拠ギルドが定期的にチップを請求する API と UI。
- **デルポイの効果**: 敵の Guild XP や進軍予定のマップ上表示。
- **ヘルメスの効果**: スタミナ回復 +20%・拡大 XP -10% の適用（スタミナ/拡大コスト計算への組み込み）。
- **日次ランキングスナップショット**: 毎日 `grand_floor_daily_ranking` に書き込む cron またはジョブ。
- **ランキング報酬**: 1 位／2–3 位／4–10 位／参加賞のリソース配布ロジックと UI。
- **マップ上での拡大・占領**: セルタップで拡大/占領を実行する UI とコスト表示・確認ダイアログ。
