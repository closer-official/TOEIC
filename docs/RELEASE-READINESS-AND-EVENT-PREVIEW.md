# リリース可否とイベント確認方法

## 現在のリリース可否（要確認項目）

### 実装済み・利用可能
- **認証**: ログイン / 退会（データ全削除）
- **ホーム**: スタミナ・チップ表示、ゲームモード選択（Part5全国・単語全国・単語For You）
- **ゲーム**: Part5 / 単語の出題、サバイバル、結果画面（Score・獲得XP・装着装備の簡易表示）
- **ランキング**: 個人（Part5/単語）のランキング
- **進化**: 個人の研鑽の極意・至高の技巧・魂の燃焼（シーズン制）
- **装備**: 取得・装着・レベルアップ・進化・廃棄、インベントリ・装備の本
- **ギルド**: 設立（30,000 ギルドXP）・参加・脱退・チャット・メンバー・研究室（XP/スコア/スタミナ）
- **取引**: XP→チップ（1 XP = 0.01 チップ）、XP→ギルドXP、マーケット
- **ショップ**: チップパック・サブスク（Pro/VIP）、ガチャ（装備のみ）、スタミナ回復
- **設定**: プロフィール・キー設定・退会
- **イベント**: 運命のすごろく・摩天楼のタワー・至高の1番くじ（プレイ可能）。他は準備中

### Coming soon（表記済み）
- **ギルドランキング**: ギルドタブ内で「Coming soon...」表示
- **THE GRAND FLOOR（ギルドマップ）**: ギルドタブ内で「Coming soon...」表示

### リリース前に確認推奨
- [ ] 本番環境の Supabase マイグレーション（例: `run_question_ids`）が適用されているか
- [ ] Stripe 本番の価格ID・Webhook が設定されているか
- [ ] 利用規約・プライバシー・/info の文言が最新か
- [ ] 単語・Part5 問題データが本番で想定どおりか（件数・品詞非表示）

## イベントの中身を自分だけ確認する方法

**開発者用プレビュー**で、週替わりに関係なく実装済みイベントの画面を開けます。

1. イベント一覧ページを開く  
   `https://あなたのドメイン/event`
2. URL に **`?preview=1`** または **`?dev=1`** を付ける  
   `https://あなたのドメイン/event?preview=1`
3. ページ内の **「開発者用プレビュー」** セクション（オレンジ枠）が表示される
4. 表示されたボタンから、次のいずれかに遷移してプレイ画面を確認できる  
   - 運命のすごろく → `/event/sugoroku`  
   - 摩天楼のタワー → `/event/tower`  
   - 至高の1番くじ → `/event/ichiban`

通常ユーザーは `/event` だけを開くため `?preview=1` を付けず、このセクションは表示されません。自分だけ確認したいときは上記 URL をブックマークしておくと便利です。
