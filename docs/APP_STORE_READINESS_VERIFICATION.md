## 結論：申請「できる」か

| 申請のしかた | 判定 | 条件 |
|--------------|------|------|
| **無料アプリとして申請**（アプリ内で課金しない） | ✅ **申請可能** | iOS アプリ内でチップ・サブスクの**購入導線を出さない**（ショップを非表示／「Webで購入」案内のみ等）にする必要あり。 |

## 申請を阻害する／要対応の項目

### 1. 課金方式（最重要）

| 現状 | リスク |
|------|--------|
| ショップ（`/shop`）で **チップ購入・サブスク** を **Stripe**（Embedded Checkout / checkout-subscription）で提供している。 | **App Store 経由のアプリ**で、アプリ内でデジタル商品（チップ・サブスク）を売る場合は **Apple のアプリ内課金（IAP）が必須**。Stripe のみだと **Guideline 3.1.1** で却下される可能性が非常に高い。 |

**取りうる対応**

- **A) 無料アプリとして申請する**  
  - iOS アプリ内では「チップ購入」「サブスク」の**購入ボタン・Stripe 決済を出さない**。  
  - ショップ画面を非表示にするか、「チップ・サブスクは Web 版（ブラウザ）でご利用ください」と案内のみにする。  
  - 審査時には「アプリ内では課金しない」ことを説明する。
- **B) Apple IAP を実装する**  
  - iOS ではチップ・サブスクを **StoreKit 2（IAP）** で販売し、Web は Stripe のままにする。  
  - 購入の復元（Restore）ボタンも必要。

現状のまま（アプリ内で Stripe で売る）で提出すると **却下リスク大** です。

### 2. App Store Connect 側で申請前に用意するもの

| 項目 | 内容 |
|------|------|
| **年齢レーティング** | App Store Connect で該当するレーティングを選択。 |
| **カテゴリ** | 教育 or ゲームなど、アプリの内容に合うカテゴリを選択。 |
| **スクリーンショット** | 各デバイスサイズ用（6.7", 6.5", 5.5" 等）のスクリーンショットを用意。 |
| **説明文・キーワード** | 短い説明・宣伝文・キーワードを用意。`docs/APP_STORE_CONNECT_COPY.md` 等を参照可。 |
| **サポート URL** | 問い合わせ先と一致させる（例: 会社概要ページの URL または `mailto:info@closer-official.com` を案内するページ）。 |
| **プライバシーポリシー URL** | 本番の `/privacy` の絶対 URL（例: `https://shun.closer-official.com/privacy`）を設定。 |
| **レビュー用メモ** | 審査担当向けに、**問い合わせ先（メール・電話）**・テスト用アカウント（必要なら）を明記。 |

## 申請フロー（無料アプリとして出す場合の目安）

1. **iOS 側で課金導線を外す**  
   - アプリ内で `/shop` を非表示にする、またはショップ内の「チップ購入」「サブスク」を押しても **Stripe を開かず**「Web版でご利用ください」等の案内のみにする。
2. **Mac でビルド**  
   - `git pull` → `npm run build:ios` → `npx cap sync ios` → Xcode で **Product → Archive**。
3. **App Store Connect**  
   - アプリ登録・メタデータ（説明・スクリーンショット・プライバシーURL・サポートURL・年齢・カテゴリ）を入力。  
   - Archive を **Distribute App** → App Store Connect にアップロード。  
   - 該当ビルドを選び **審査に提出**。  
   - レビュー用メモに問い合わせ先を記載。
4. **審査**  
   - 「アプリ内では課金しておらず、有料機能は Web 版で提供」であることを説明できるようにしておく。
