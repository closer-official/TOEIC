# Stripe 本番審査「ウェブサイト確認」で必要なこと

## 審査で「ウェブサイトに関する情報を提供してください」「期限超過」になる主な理由

Stripe のヘルプにあるとおり、以下が満たされていないと本番利用が承認されません。

1. **パスワードなしでアクセスできること**  
   審査担当があなたのサイトにアクセスしたとき、**ログインや会員登録なしで**ビジネス情報を確認できる必要があります。

2. **「作成中」「未完成」に見えないこと**  
   トップがログイン画面だけだと「サイトが未完成」と判断され、本番利用が許可されないことがあります。

3. **次の情報がサイト上に明示されていること**
   - **ビジネス名**（Stripe に提出した名称と一致）
   - **販売している商品・サービスの説明**
   - **カスタマーサポートの連絡先**（メール・電話・住所のいずれか／お問い合わせフォーム等）
   - **返金・不審請求・キャンセルに関するポリシー**（該当する場合）

---

## 現状のアプリで問題になりやすい点

| 要件 | 現状 | 問題の可能性 |
|------|------|----------------|
| パスワードなしでアクセス可能 | ルート `/` は未ログイン時は **即ログイン画面へリダイレクト** | **高** — 審査担当がトップに来るとログイン画面しか見えず「サイト未確認」と判断されやすい |
| ビジネス名・サービス説明がすぐ分かる | ログイン後の画面にはあるが、**未ログインでは見られない** | **高** — 審査はログインせずに確認する想定 |
| 会社概要 | `/about` は **ログイン必須** のうえ、**外部サイトへ転送** | **高** — 自ドメインに事業者情報が残らない |
| 利用規約・特商法・プライバシー | `/terms`, `/tokusho`, `/privacy` は **ログイン不要で表示可能** | 低 — 直リンクなら確認できる |
| よくある質問・お問い合わせ先 | `/faq` は **ログイン必須** | 中 — 連絡先がログインなしで一覧しづらい |

結論として、**「Stripe が登録されたウェブサイトの URL（多くの場合はルート）にアクセスしたときに、ログインなしでビジネス情報が一通り見られるページ」が無い**ことが、審査で何度も「ウェブサイトを確認できませんでした」になる一番の原因と考えられます。

---

## 審査員用の「ログインページ」は必要か

**不要です。**  
Stripe の要件は「**パスワードなしで**アクセスできること」なので、審査員専用のログインや特別な認証は逆効果です。  
必要なのは、**誰でも（ログインせずに）見られる「ビジネス・サービス説明ページ」** です。

---

## 推奨対応：審査用の「公開説明ページ」を用意する

次のどちらか（または両方）を行うことを推奨します。

### 1. 公開の「事業者・サービス情報」ページを追加する（推奨）【実装済み】

- **パスなしでアクセス可能**なページ **`/info`** を用意済み（`src/app/info/page.tsx`）。
- そのページに以下をまとめて載せる：
  - **ビジネス名**: Closer事務局（Stripe に提出した名称と同一）
  - **サービス名・説明**: SHUN（瞬）— TOEIC Part5・英単語の学習アプリ、アプリ内通貨（Chips）・サブスクリプションの販売
  - **連絡先**: メール（info@closer-official.com）、電話、住所（特定商取引法に基づく表記と同一で可）
  - **利用規約・プライバシーポリシー・特定商取引法に基づく表記** へのリンク
  - **返金・キャンセル**: デジタルコンテンツのため原則返品不可、不具合時はメールで連絡など（特商法ページと一致させる）

### 2. Stripe ダッシュボードで「ウェブサイトの URL」をそのページに合わせる

- Stripe ダッシュボードの **「ウェブサイトに関する情報」** → **「Web サイトを更新」** で、  
  **ビジネスのウェブサイト URL** を  
  - ルート `https://shun.closer-official.com/`（ログインリダイレクトになるため非推奨）ではなく  
  - **公開ページ** `https://shun.closer-official.com/info` に変更する。
- 審査担当がその URL を開いたときに、**ログインなしで** 上記の情報がすべて見える状態にしておく。

---

## 運用上の注意

- この公開ページは **審査のためだけでなく、一般のお客様が事業者情報を確認する用途** にも使えるようにしておくとよいです。
- ルート `/` を未ログイン時も「説明ページ」にする場合は、**「ログイン」「ゲストで利用」** などのリンクで従来のフローに誘導する設計にすると、審査とユーザー体験の両立がしやすくなります。
