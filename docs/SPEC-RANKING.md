# 全国ランキング 仕様

## 現在の仕様（修正前の整理）

### 保存条件
- **POST /api/runs** に送るのは **ログイン済み** かつ **mode が part5-national または vocab-national** のときのみ。
- **未ログイン** の場合は `userIdRef.current` が null のため **スコアは送信されず保存されない**。

### スコアの計算（修正前）
- `goToResult` 内で **`results.filter((r) => r.correct).length`**（正解数）のみを送っていた。
- サバイバルモードの **コンボによる加算（10コンボ以上で2点／問）** は **ランキング用スコアに反映されていなかった**。

### API・表示
- **POST** body: `{ userId, score, totalTimeMs }`。Supabase の `runs` テーブルに保存。
- **GET** `/api/runs?limit=20`: スコア降順・同点なら total_time_ms 昇順で取得。
- ランキング画面: 「○ 問正解」「○秒」を表示。

---

## 修正内容

1. **ランキング用スコア**  
   - **サバイバルモード**（ランク選択済み）のときは、ゲーム中の `score` 状態（10コンボ以上で2点／問を含む）をそのまま送る。  
   - それ以外は従来どおり「正解数」を送る。

2. **未ログイン時**  
   - スコアは送信されず保存されない。ランキング画面に「ログイン時のみ保存」の注記を追加済み。

3. **表示**  
   - ランキング一覧のスコア表示を「○ 問正解」→「○ pt」に変更（サバイバルスコアと正解数の両方に対応）。
