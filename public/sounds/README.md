# 効果音・BGM の配置場所

このフォルダに以下のファイルを置くと、アプリで再生されます。**ファイルが無い場合は再生されず、エラーにもなりません。**

## メニューBGM（ホーム・ダッシュボード等）

| ファイル名   | 説明 |
|-------------|------|
| `bgm-menu.mp3` | アプリ全体で流れるBGM。ヘッダーの🎵ボタンでON/OFF。 |

## ゲーム中

| ファイル名   | 説明 |
|-------------|------|
| `bgm-normal.mp3`  | 通常プレイ中のBGM |
| `bgm-urgent.mp3`  | 残り5秒のときのBGM |
| `bgm-fever.mp3`   | FEVER中のBGM |
| `combo-great.mp3` | コンボ「Great」時 |
| `combo-excellent.mp3` | コンボ「Excellent」時 |
| `perfect-bonus.mp3`  | パーフェクトボーナス時 |
| `boss-warning.mp3`   | ボス警告時 |
| `time-stop.mp3`      | タイムストップ時 |

- 形式は **MP3** を推奨（ブラウザ対応が広い）
- メニューBGMはループ再生されます
